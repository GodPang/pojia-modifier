# v1.05.0-beta

测试版。新增 TeleAgent 目标，支持范围 20 → 21；顺手修掉 asar 读取层对新版 Electron
头格式的误判。

## 新增目标：TeleAgent

TeleAgent 是电信"星辰超级智能体"桌面版（Electron + Go 内核，主逻辑用 bytenode 编译）。
它把账号隔离目录下 `memory/` 里的四个文件列进 agent 配置的 `instructions` 数组，每次
会话整份注入 system prompt —— 其中 `USER.md` 是"用户长期记忆"，天然适合放人格与政策。

破甲落点选 `<设备根>/users/<ownerDir>/memory/USER.md`，用标记块与用户原有内容共存：

- **不碰程序本体**：`D:\TeleAgent` 安装目录、`app.asar`、bytenode 的 `.jsc` 一律不写。
- **账号隔离**：`ownerDir` 从 `current-owner.json` 读，运行期按登录账号生成，不写死；
  多账号时只对当前登录的那个动手。
- **可逆、幂等**：改前旁路备份，标记块独立增删；重复注入字节不变，`--revert` 逐字节
  还原（含 BOM 与行尾）。
- 检测到 TeleAgent 进程在跑时提示"重开会话/重启后生效"，默认不结束进程。

命令行：`--target teleagent`，可用 `--teleagent-dir <账号根>` 手动指定落点根目录。

## 优化

- **asar 头兼容新旧两种格式。** 旧 Electron 的 asar 头是 `[u32 size][u32 json_size]`，
  TeleAgent 3.x 换成了 16 字节的四 u32 布局，旧解析器按偏移读会在 JSON 之前多读 8 字节、
  直接解不出头。现在先按新格式试解、失败再回落旧格式，两条路都验证 JSON 含 `files`
  才认。
- **修正 `asar_read_file` 的路径遍历。** 原实现每段都套 `.get("files").get(part)`，
  第一段就从根多取了一层 `files`，导致任何路径都读不到文件；改成根取一次、后续按目录
  下钻。WorkBuddy 从 asar 里找标准预设模板的路径因此一并恢复。
